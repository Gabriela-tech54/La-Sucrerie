🍰 La Sucrerie

A leveza que adoça a vida.

La Sucrerie é um projeto de site para uma confeitaria artesanal, criado para apresentar a marca, seus produtos e proporcionar uma experiência de compra elegante, delicada e simples.

O projeto nasceu com foco em uma identidade visual sofisticada, inspirada na confeitaria francesa, mas mantendo uma linguagem acolhedora e artesanal.

✨ Sobre a marca

A La Sucrerie foi pensada para transformar doces em experiências.

A proposta visual combina delicadeza, elegância e calor, tendo os macarons como produto de destaque e uma identidade construída ao redor de:

tons creme;

rosé e pêssego;

vinho;

marrom quente;

tipografia elegante;

detalhes artesanais.

Slogan:
A leveza que adoça a vida.

🛍️ Sobre o projeto

O site foi desenvolvido como uma loja virtual em construção.

Atualmente, a página apresenta:

página inicial com seção Hero;

identidade visual da La Sucrerie;

produtos em destaque;

cardápio com categorias;

filtros de produtos;

seção sobre a marca;

formulário de newsletter;

carrinho de compras funcional;

alteração de quantidade dos produtos;

cálculo automático do total;

menu responsivo para dispositivos móveis.

💻 Tecnologias utilizadas

O projeto utiliza tecnologias web fundamentais:

HTML5 — estrutura das páginas;

CSS3 — layout, responsividade e identidade visual;

JavaScript — interações e funcionalidades da loja.

Também são utilizadas fontes externas para complementar a identidade visual.

Direção visual

A identidade busca transmitir:

elegância + delicadeza + artesanal + acolhimento

O objetivo é que o cliente reconheça a La Sucrerie mesmo sem precisar ler o nome da marca.

🧁 Produtos

O projeto possui uma estrutura preparada para trabalhar com diferentes categorias:

Macarons

Geladinhos

Doces especiais

Caixas para presente

Os produtos atualmente presentes no código são demonstrativos e poderão ser substituídos pelos produtos e preços reais da La Sucrerie.

🛒 Carrinho

O carrinho atualmente funciona no navegador e permite:

adicionar produtos;

aumentar a quantidade;

diminuir a quantidade;

remover produtos ao chegar a zero;

visualizar o subtotal;

visualizar o total da compra.

O checkout ainda não está conectado a um sistema real de pedidos ou pagamento.

📱 Responsividade

O site foi desenvolvido para se adaptar a diferentes tamanhos de tela:

💻 computador;

💻 notebook;

📱 celular;

📱 tablet.

A navegação e os cards são reorganizados automaticamente em telas menores.

🚧 Próximas etapas

O projeto ainda está em desenvolvimento.

As próximas etapas planejadas incluem:

substituir as imagens provisórias por fotografias reais dos produtos;

criar páginas individuais para cada produto;

melhorar a busca;

criar um checkout real;

integração com WhatsApp para pedidos;

integração com pagamento;

armazenamento real de produtos e pedidos;

painel administrativo;

publicação do site em produção;

domínio oficial da La Sucrerie.
